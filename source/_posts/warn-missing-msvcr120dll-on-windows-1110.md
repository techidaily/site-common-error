### Fix 1: Change the media player

 The 0xc00d5212 error message pops when some Windows Media Player users try to play AVI videos. “This item was encoded in a format that’s not supported.” Thus, changing the media player is the fast and easiest way to let you watch the video.

 Download a free media player that supports more codecs and file formats than Windows Media Player. Then play the video you’d like to watch. VLC Media player could be a good option.

 If changing the media player doesn’t help, your video file might be corrupted. You can move to[Fix 4](#f4) to repair your video file.

### Fix 2: Install the missing codec

 Lack or missing important codecs can cause the 0xc00d5212 error. Therefore, downloading and installing the correct or missing codes would solve the problem. Note that this method doesn’t work for Windows Media Players 12.  
 Here’s how to determine your version of Windows Media Player version and how to download codecs:

1. Run Windows Media Player.
2. Press**ALT + H** on your keyboard and click**About Windows Media Player** .  
![](https://images.drivereasy.com/wp-content/uploads/2022/07/media-1.jpg)
3. Check the version.**If it’s 12, move to another fix** . If it’s 11, move to the next step.  
![](https://images.drivereasy.com/wp-content/uploads/2022/07/media-2.jpg)
4. Click**Organize > Options…**
